# 3D 仓储管理系统场景构建精确描述文档

## 一、 整体氛围与构图设置
*   **风格定位**：科技感、现代化、高亮明快（白昼环境）、等距视角（Isometric / 3/4 斜视角），适合管理系统的 3D 俯瞰图。
*   **摄像机视角**：固定在 45 度俯视角度（类似 `OrbitControls` 下的初始视角），场景居中且略带轻微旋转。
*   **环境背景**：纯白色或极浅的灰色背景（`#FAFAFA`），无强烈天光，主要光源为环境光和方向光。整体画面通透、干净。

## 二、 核心建筑与结构（Central Warehouse）
*   **建筑主体形态**：大型、长方形、多跨度的现代化工业厂房/物流中心。
*   **材质与形式**：
    *   **外立面**：大面积**高透玻璃幕墙**（Glass），垂直拼接、黑色金属框架分割。
    *   **边框与主体骨架**：亮银色或纯白色的钢结构（`Metallic` 材质）。
    *   **建筑底部**：墙面为白色实体，带有 3 个并排的**深蓝色工业卷帘门/装卸口**。
*   **内部透视（重点难点）**：玻璃应具备一定的反射和折射，让内部结构半可见。内部可以看到**浅蓝色的高亮货架**（呈现 X 型或网格状排列），并散发微弱的**淡蓝色内透光（点光源或发光材质）**。
*   **屋顶结构**：平坦屋顶。
    *   **大面积覆盖物**：深色的 **太阳能光伏板（Solar Panels）** 整齐排列在屋顶右侧。
    *   **设备**：屋顶上散落着几个浅灰色的**方形空调/通风机组（HVAC units）**。

## 三、 地面与物流编排
*   **地面材质**：纯白色的平面（带轻微光泽度，类似磨砂亚克力或高亮环氧地坪）。地面上带有非常浅的灰色网格线，用于划分物流区域。
*   **左侧货物堆叠区（堆场）**：
    *   **堆叠方式**：排列整齐的矩形方块（BoxGeometry），代表不同规格的货物。
    *   **集装箱**：高饱和度**蓝色**，带有顶部和底部的金属件细节。
    *   **托盘/纸箱**：**棕色（牛皮纸色）**纸箱，堆叠呈现 2x2 或 3x3 的金字塔排列，边缘有白色的打包带细节。
    *   **散货区**：白色泡沫箱或塑料周转箱的局部堆叠。

## 四、 交通动线与车辆
*   **立体高架桥（架空公路）**：
    *   从右侧高处延伸，弯曲并横跨建筑，由白色混凝土桥墩支撑。
    *   **桥面**：深灰色沥青路面，带有白色的车道虚线（黄色实线）。
*   **车辆（卡车）**：
    *   场景内有多辆**重型集装箱卡车（Semi-trucks）**。车头为**蓝色**，拖挂的集装箱为**白色或浅灰色**。
    *   **位置分布**：
        1.  高架桥上：一辆红蓝色卡车和一辆白色卡车正沿曲线行驶。
        2.  建筑右侧卸货区：两辆白色卡车停靠（一辆靠近门口）。
        3.  地面主干道（前景）：一辆蓝色货车由左向右行驶。
        4.  左上角远景：一辆蓝色卡车驶向远处。

## 五、 伴生建筑
*   **左上角附属建筑**：
    *   较小体量的白色二层办公楼或调度中心。
    *   **建筑形式**：平顶，带有一圈蓝色的装饰线条，屋顶同样有空调外机。侧面有一个蓝色的门和白色斜坡。

## 六、 技术材质与光照参数（供 Three.js 配置）
*   **照明系统**：
    *   **Ambient Light (环境光)**：柔和，`intensity` 建议 0.6，颜色 `#FFFFFF`。
    *   **Directional Light (平行光)**：主光源，模拟太阳光，角度呈 45 度从左上前方照射。投射阴影（`castShadow: true`）。
    *   **仓库内透光**：在玻璃仓库内部放置 2~3 个 `PointLight` 或使用 `Emission Map`，颜色设为 `#0044FF` 或 `#00BFFF`，产生科技蓝光感。
*   **材质属性（Material）**：
    *   地面：`MeshStandardMaterial`，`roughness: 0.9`, `metalness: 0.0`，接收阴影。如果需要网格线，叠加一个 `GridHelper`。
    *   仓库玻璃：`MeshPhysicalMaterial`，`transmission: 0.9`, `roughness: 0.1`, `ior: 1.5`，`opacity` 根据需求调整。
    *   屋顶太阳能板：深灰色 `MeshStandardMaterial`，表面带有蓝色的微光。
*   **阴影设置**：开启 `renderer.shadowMap`，所有卡车、建筑、桥墩都需投下清晰的阴影，以此增强 3D 空间的立体感。
